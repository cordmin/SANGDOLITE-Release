생활기록부 도우미 개인정보 처리방침

시행일: 2026년 11월 17일
제공자: 이경민 (충남교육청 교사)

AI 문장 생성 시 입력한 활동 내용·관찰 기록 등이 이용자가 넣은 API 키로 이용자의 브라우저에서 Google Gemini API로 직접 전송됩니다. 학생 이름, 연락처, 학번 등 식별정보와 민감하거나 비밀인 내용은 입력하지 마세요. 입력 내용을 자동으로 익명화하는 기능은 없습니다.

1. 처리 목적과 항목

교사가 학생의 활동 및 관찰 내용을 바탕으로 생활기록부 문장 초안을 작성하고, 결과를 확인·수정·엑셀로 저장하도록 돕습니다. 활동 영역, 선택·직접 입력한 활동 내용, 학생 관찰 기록, 과목명·동아리명, 선택한 생활 태도 키워드, 생성 글자 수와 문장 개수, 생성 결과를 처리합니다. 자유 입력 내용에 개인정보가 포함되면 그 정보도 처리 대상이 될 수 있습니다.

이 프로그램은 교사를 위한 작성 보조 도구입니다. 학생을 자동으로 평가·선발하거나 공식 기록을 확정하지 않으며, 생성 결과의 사실관계와 적정성은 교사가 검토해야 합니다.

2. AI 생성과 외부 전송

‘문장 생성하기’를 누르면 현재 생성 요청의 활동 영역, 활동·관찰 내용, 과목명·동아리명, 선택 키워드, 생성 옵션과 작성 지침이 이용자의 브라우저에서 이용자의 API 키로 Google Gemini API에 직접 전송되고, 생성된 응답이 화면에 표시됩니다. 제공자의 서버를 거치지 않으며, 제공자는 입력 내용과 API 키를 받거나 볼 수 없습니다. 입력 내용을 화면에 적는 것만으로 AI 생성 요청이 전송되지는 않습니다.

API 사용량·요금과 Google 계정의 데이터 이용 설정은 API 키를 만든 이용자의 Google 계정 조건에 따릅니다.

Google의 입력·출력 이용 방식은 API의 유료·무료 사용 조건과 계정 설정 등에 따라 달라집니다. Google은 무료 서비스에 민감정보·기밀정보·개인정보를 제출하지 않도록 안내하고, 입력·출력이 서비스 개선 및 검토에 사용될 수 있다고 명시합니다. 이 프로그램은 API의 실제 결제·보관 설정을 화면에서 확인하지 못하므로, 입력 내용이 학습에 사용되지 않는다거나 즉시 삭제된다고 보장하지 않습니다.

Gemini API 이용약관 및 데이터 이용 안내 · Google 개인정보처리방침

3. 저장 위치·보유 기간·삭제

현재 화면의 입력 내용, 메뉴별 작업 상태와 생성 결과는 브라우저 메모리에서 유지됩니다. 현재 소스에는 가져온 엑셀·PDF와 점검 결과도 메모리에서만 처리합니다. 이 작업 내용을 새로 영구 저장하는 기능이 없으며, 새로고침하거나 탭을 닫으면 작업 상태가 초기화됩니다. 다만 브라우저의 세션 복원·캐시 등 별도 기능에 따른 보관은 브라우저 설정을 따릅니다.

설정에서 넣은 API 키와 고른 AI 모델은 이 브라우저의 저장소(localStorage)에만 저장되며 제공자에게 전송되지 않습니다. 같은 기기의 같은 브라우저를 쓰는 다른 사람이 볼 수 있으므로 공용 컴퓨터에서는 사용 후 설정에서 API 키를 지우세요. 이 사이트의 저장 자료를 모두 지우려면 브라우저 설정에서 이 사이트의 저장된 데이터·캐시를 삭제하세요. 직접 내려받은 엑셀, 복사한 문장, 백업·공유 파일은 별도로 삭제해야 합니다.

Google 등 외부 서비스가 처리하는 자료·기록의 보유 기간과 삭제 절차는 해당 서비스의 정책 및 운영 설정에 따릅니다. 화면을 초기화하거나 탭을 닫는 것으로 이미 외부에 전송된 내용이 삭제되지는 않습니다.

맞춤법 보조 점검은 이 사이트에 포함된 Hunspell 한국어 사전 0.7.94과 hunspell-wasm으로 브라우저 안에서 처리합니다. 외부 맞춤법 서비스로 학생 기록을 전송하지 않습니다. 사전의 출처와 이용 조건은 라이선스 안내를 참고하세요.

4. 외부 통신과 국외 처리

AI 생성에는 Google Gemini API를 사용합니다. 화면을 열 때 Tailwind CSS(cdn.tailwindcss.com), Pretendard 글꼴 및 엑셀 라이브러리(cdn.jsdelivr.net), PDF 라이브러리(cdnjs.cloudflare.com), Lucide 아이콘(unpkg.com)을 외부 서버에서 불러옵니다. 이 과정에서 IP 주소, 요청 시각, 브라우저·기기 정보 등 접속 정보가 각 서비스에 전달될 수 있습니다. 글꼴·라이브러리 요청에 활동·관찰 기록을 의도적으로 포함하지는 않습니다.

입력 내용 및 접속 정보는 Google과 CDN 제공자의 국외 서버에서 처리될 수 있습니다. 구체적인 처리 국가·보유 기간은 서비스 및 배포 설정에 따라 달라지며 현재 프로그램에서 확정하지 않습니다. 개인정보를 외부로 전송하기 전에 이용자와 소속 학교는 적용되는 처리 근거, 외부 서비스 이용·국외 이전 요건을 확인해야 합니다. 이 방침의 열람은 필요한 동의나 학교의 승인 절차를 대신하지 않습니다.

5. 입력 최소화와 안전한 이용

이름, 학번, 연락처, 주소, 주민등록번호, 가족 정보, 건강·상담·장애 등 민감하거나 학생을 알아볼 수 있는 세부사항을 제외하고, 문장 작성에 필요한 일반화된 활동만 입력하세요. 이름을 빼더라도 내용의 조합으로 학생을 식별할 수 있습니다. 프로그램은 이를 자동으로 탐지하거나 제거하지 않습니다.

프로그램 자체에는 사용자별 로그인, 파일 암호화, 접근 권한 관리 기능이 없습니다. 교사와 학교는 기기 잠금, 파일 접근·공유 범위, 보유 기간과 파기를 관리해야 합니다. 문의 시 학생 자료가 담긴 파일·화면·로그를 공개 게시판에 올리지 마세요.

6. 학생·보호자의 권리와 문의

학생 또는 정당한 보호자·대리인은 소속 학교의 개인정보 담당자에게 자료의 열람·정정·삭제·처리정지를 요청할 수 있습니다. 만 14세 미만 학생의 자료를 포함해 학교 업무에 사용하는 자료의 처리 근거와 필요한 절차는 학교에서 확인해야 합니다.

제공자는 이용자의 기기에 저장된 파일이나 Google이 보관하는 자료를 직접 삭제할 수 없습니다. 이미 전송한 자료와 관련한 요청은 Google 등 해당 서비스의 절차를 확인해야 합니다.
