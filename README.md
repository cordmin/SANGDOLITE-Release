# SANGDOLITE · 생활기록부 도우미 (배포용)

중학교 학교생활기록부 문장 초안을 AI(Google Gemini)로 만들어 주는 웹 도구입니다.
**서버가 없습니다.** 각자 자기 Gemini API 키를 넣으면, 자기 브라우저에서 바로 Google로 요청을 보내 문장을 만듭니다.

## 사용 방법

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 Gemini API 키를 발급받습니다. (무료 사용량 있음)
2. 웹 주소로 접속합니다. (또는 이 저장소를 내려받아 `index.html`을 엽니다. `css`, `js`, `assets` 폴더가 함께 있어야 합니다.)
3. 사이드바 아래 **[설정 · 내 API 키]** → 키를 붙여 넣고 **[저장]**
4. 왼쪽 메뉴에서 영역을 고르고, 활동·관찰 내용을 넣은 뒤 **[문장 생성하기]**
5. 결과를 확인하고 **[결과 내려받기]**로 엑셀 저장

## 지원 영역

자율 활동 · 진로 활동 · 스포츠/동아리 활동 · 과목별 세부 특기사항 · 행동특성 및 종합의견

## 설정

사이드바 아래 **[설정 · 내 API 키]**를 누르면 작은 창이 열립니다.

- **내 API 키**: 붙여 넣고 저장, 휴지통으로 지우기 (앞뒤 4글자만 보임)
- **AI 모델**: 기본(`gemini-flash-lite-latest`) 또는 목록에서 고르기, 직접 입력

## 저장과 개인정보

- API 키와 모델은 **이 브라우저(localStorage)에만** 저장되며 제작자에게 전송되지 않습니다.
- 공용 컴퓨터에서는 사용 후 설정에서 API 키를 지워 주세요.
- 입력한 내용은 문장 생성 시 Google Gemini API로 전송됩니다. 학생 이름 등 알아볼 수 있는 정보는 넣지 마세요.
- 자세한 내용은 화면 아래 **개인정보 처리방침**을 확인하세요.
