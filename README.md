# SANGDOLITE (생활기록부 작성 도우미 - 배포용)

> **2026학년도 학교생활기록부 기재요령**을 완벽 반영한 인공지능(AI) 기반 생활기록부 작성 보조 프로그램입니다.  
> 별도의 서버 호스팅이나 복잡한 설치 없이, **`index.html` 단일 파일**만 브라우저로 열어 즉시 사용하실 수 있습니다.

---

## ✨ 주요 특징

1. **무설치 & 단일 파일 실행**
   - 다운로드한 `index.html` 파일을 더블 클릭하기만 하면 크롬, 엣지, 웨일 등 모든 최신 웹 브라우저에서 바로 실행됩니다.
2. **철저한 개인정보 & API 키 보안**
   - 사용자 입력 데이터 및 Gemini API 키는 제작자나 외부 서버로 전송되지 않으며, 사용자 PC의 브라우저(로컬 스토리지)에만 안전하게 보관됩니다.
   - 모든 AI 생성 요청은 사용자의 브라우저에서 Google 공식 Gemini API 서버로 직접 안전하게 암호화 통신합니다.
3. **2026학년도 기재요령 가이드라인 준수**
   - 금지어(외부 수상 실적, 공인어학시험, 도서 출판, 모의고사 등) 및 주의사항을 철저히 검증하여 작성합니다.
   - 학생의 개별 역량, 구체적 성장 과정, 교사의 관찰 내용 중심의 자연스러운 문장으로 생성합니다.
4. **나이스(NEIS) 바이트 글자수 실시간 계산**
   - 나이스 규격(한글 3바이트, 영문/숫자/기호 1바이트, 줄바꿈 2바이트)에 맞춘 정확한 바이트 계산 및 표시.
   - 글자수 제한(500자/1500바이트 등)에 맞춤형 옵션 제공.
5. **원클릭 엑셀(.xlsx) 내보내기**
   - 생성된 학생별 생기부 문구를 번호, 작성 내용, 나이스 바이트 수까지 포함하여 깔끔하게 엑셀로 저장할 수 있습니다.
6. **미래 지향적 AI 아키텍처 (Future-Proof)**
   - **실시간 모델 자동 동기화**: API 키를 입력하면 구글 서버에서 현재 사용 가능한 최신 모델 목록을 실시간으로 자동 조회합니다.
   - **영구 별칭 모델 지원**: `gemini-flash-lite-latest`를 지원하여 모델 세대가 바뀌어도 코드 수정 없이 항상 최신 모델을 가리킵니다.
   - **지능형 자동 복구 (Smart Failover)**: 선택한 모델이 구글에서 지원 종료(404/deprecated)되어도 안정적인 최신 모델로 자동 대체하여 생성을 완수합니다.
   - **API 엔드포인트/버전 자유 설정**: 사이드바 하단 [API 고급 설정]을 통해 구글 API 주소나 버전을 자유롭게 변경할 수 있습니다.

## 🚀 사용 방법

### 1단계: 무료 Gemini API 키 발급
1. [Google AI Studio (API 키 발급 페이지)](https://aistudio.google.com/apikey)에 접속하여 구글 계정으로 로그인합니다.
2. **[Create API key]** (또는 API 키 만들기) 버튼을 클릭합니다.
3. 생성된 API 키를 복사합니다. (무료 플랜으로도 충분한 양의 생기부 작성이 가능합니다.)

### 2단계: 프로그램 실행
1. 본 저장소에서 `index.html` 파일을 다운로드합니다.
2. 다운로드한 `index.html` 파일을 더블 클릭하여 실행합니다. (Chrome, Edge, Whale 브라우저 권장)

### 3단계: API 키 및 모델 설정
1. 화면 좌측 사이드바 하단의 **[Gemini API 키]** 입력란에 복사한 키를 붙여넣습니다. (자동으로 브라우저 로컬에 안전하게 저장됩니다.)
2. 필요 시 **[Gemini 모델]** 목록에서 원하는 모델(`gemini-3.5-flash-lite`, `gemini-3.5-flash`, `gemini-3.5-pro` 또는 직접 입력)을 선택합니다. (기본값: 가장 빠르고 무료 할당량이 넉넉한 `gemini-3.5-flash-lite`)
3. 좌측 메뉴에서 작성할 영역(**자율활동**, **진로활동**, **동아리활동**, **교과세특**, **행동특성 및 종합의견**)을 선택합니다.
4. 활동 내용 및 학생 관찰 사항을 입력하고 **[생기부 문장 생성]** 버튼을 클릭합니다.
5. 생성 결과를 확인한 후 필요 시 **[엑셀 다운로드]** 버튼을 눌러 파일로 저장합니다.
