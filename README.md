# 생활기록부 도우미 · 개인 API 버전

각자의 Gemini API 키로 문장을 생성하는 정적 웹 앱입니다. GAS나 관리자 비밀번호는 사용하지 않습니다.

현재 작성 지침은 **v2.1.9**입니다. 서버용 앱의 같은 버전 지침을 그대로 반영했습니다.

## 실행

이 폴더 전체를 정적 호스팅에 올리거나, 이 폴더에서 다음 명령을 실행합니다.

    python -m http.server 8010 --bind 127.0.0.1

브라우저에서 http://127.0.0.1:8010/ 을 엽니다. 맞춤법 Web Worker와 사전은 HTTP 또는 HTTPS가 필요하므로 index.html을 더블클릭해서 실행하지 마세요.

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 본인의 API 키를 준비합니다.
2. **API키 설정**에서 키와 모델을 저장합니다.
3. 영역을 고르고 활동·관찰 내용을 입력해 문장을 생성합니다.
4. 결과를 확인한 뒤 엑셀로 내려받습니다.

## 반영된 기능

- 최신 기본 작성 지침, 영역별 생성 글자 수 및 1~50개 생성
- 문단 끝의 개별 복사 버튼, 실제 글자 수·바이트 두 줄 표시
- 생성 결과에는 자동 점검을 붙이지 않으며, 보조 점검은 별도 화면에서 실행
- 나이스 생활기록부 엑셀·PDF 보조 점검, 검색·필터 및 점검 결과 엑셀 저장
- 로컬 Hunspell 한국어 사전과 라이선스 안내
- 출력 한도나 통신 오류 발생 시 실제 완성 개수 표시와 완성 문단 보관

## 저장과 통신

- API 키와 모델만 이 브라우저의 localStorage에 저장합니다.
- 문장 생성은 브라우저에서 Google Gemini API로 직접 요청합니다.
- 불러온 엑셀·PDF와 맞춤법·보조 점검은 브라우저 안에서 처리합니다.
- 입력 및 작업 결과는 새로고침하면 초기화됩니다. 필요한 결과는 내려받으세요.
- 공용 컴퓨터에서는 사용 후 설정에서 API 키를 삭제하세요.
- API 이용 조건·요금·데이터 처리는 본인 Google 계정의 조건을 확인하세요.

## 파일과 수정

index.html, css, js, assets, vendor를 함께 배포해야 합니다.
assets/hunspell-ko와 vendor/hunspell-wasm 및 라이선스 파일을 빠뜨리지 마세요.
맞춤법 구성과 출처는 [HUNSPELL.md](HUNSPELL.md)를 참고하세요.

작성 지침은 js/guide-default.js, 보조 점검 규칙은 js/record-check.js에서 수정합니다.
작성 규칙은 guide-default.js 한 곳에만 두고 생성 코드에서 숨은 규칙을 추가하지 않습니다.
활동명으로 문장 시작, 연결어·글자 수 꼬리 문구 금지, 분량 지침을 포함합니다.
선택한 글자 수는 그대로 전달하며 자동 재요청·분량 맞추기용 잘라내기를 하지 않습니다.
LLM의 실제 생성 분량에는 편차가 남을 수 있습니다. 변경 이력과 확정본은 [VERSION_HISTORY.md](VERSION_HISTORY.md), docs/guide-versions/에 보관합니다.
개인 API 설정과 직접 호출은 js/app.js에서 처리합니다.
개인의 API 키나 원본 학생 자료를 배포 파일에 넣지 마세요.
